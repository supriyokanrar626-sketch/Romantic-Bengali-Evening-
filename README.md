# 🌸 Sharodiya Melody

> A little collection of soft Bengali love songs for peaceful Durga Puja evenings. ❤️

**Sharodiya Melody** is a simple web-based music player created for the festive days of **Durga Puja**.

The idea is simple — one beautiful background, a collection of soft Bengali songs, and a peaceful atmosphere to enjoy during the Puja days. 🎶🌸

## ✨ Features

- 🎵 YouTube Playlist Integration
- ❤️ Soft Bengali Love Songs
- ▶️ Play / Pause Controls
- ⏭️ Next & Previous Song
- 📊 Song Progress Bar
- 🕐 Current & Total Duration
- 🌸 Single Durga Puja Background
- 📱 Responsive Design
- 🎧 Continuous Playlist Playback
